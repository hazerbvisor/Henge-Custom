# Scratch register selection, 2026-11-10

The translator chooses temporary registers for memory operations and rewritten instructions. Replace its linear scan of 29 candidates with bit masks and count-trailing-zero operations, preserving the exact priority (x6/x7/x15, x9..x14, then the remaining allowed registers) and exhaustion behavior. There is no new cache or shared state. Generated guest translations remain identical in the tested corpus.

Two separate benchmark invocations each collect nine paired samples per scenario, alternating baseline/candidate in short batches inside one process; discard the initial warm-up round. Both use the same compiler flags and engine objects. Memory-heavy translation time fell by 4.28% / 3.50%; mixed translation by 2.77% / 3.31%. Both improved in all 18 pairs. ALU-only results were -0.36% / -0.79% (under 1% slower). See the summary JSON and raw samples attached to the release. These are synthetic emission results, not app-launch, boot or Roblox FPS measurements.

Validation: one million random used-register masks plus empty/full and single-bit cases match the original selector, including state updates and exhaustion. 20,000 original/candidate hot/cold code and literal snapshots match across flat/split layouts, grouping, slow-memory paths and execution flags. Native engine classification, operand, JIT region, JIT, memory, MMU, exception and device suites pass; device tests report 135 checks with no failures. Fixtures use a unique temporary directory, never existing VM disks. No VM settings, signing entitlements, mouse behavior, MMU checks, invalidation, locking or generated instruction semantics are intentionally changed.

Reproduce with `python3 tools/benchmark_engine.py` and `make B=build/check CC='clang -Wl,-stack_size,0x4000000' test-engine`. Keep other builds idle during timing. The test-only linker option allows large native reference stacks; app stack settings are unaffected. Physical-device boot and game frame-time testing remain pending. Publish as a prerelease for device comparison; no claim that the intermittent 40 ms game spikes are fixed.
